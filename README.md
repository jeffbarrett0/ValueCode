# Value Code

Warren Buffett ilkelerine göre hisse analizi (HTML/CSS/JS, sunucusuz).

## Kurulum
1. `config.example.js` dosyasını `js/config.js` olarak kopyalayın.
2. İçine kendi FMP API anahtarınızı yazın (https://site.financialmodelingprep.com/).
3. `index.html` dosyasını tarayıcıda açın, hisse kodunu yazın (örn. NVDA).

`js/config.js` git'e gönderilmez. Siteyi herkese açık yayınlamayın (anahtar tarayıcıda görünür).

Bu bir yatırım tavsiyesi değildir.
